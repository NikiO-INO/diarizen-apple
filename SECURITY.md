# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/NikiO-INO/diarizen-apple/security/advisories/new)
instead of a public issue. Include the commit or release, your platform, and
steps to reproduce.

## Scope

This project is a runtime and a set of conversion scripts. It runs models on
device and does not send audio or telemetry anywhere. The model weights are
third-party (see [MODELS.md](MODELS.md)) and are out of scope here; report model
issues upstream to [DiariZen](https://github.com/BUTSpeechFIT/DiariZen).
